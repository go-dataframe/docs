Notebook display

What a frame prints, and the HTML table a notebook shows, as go-dataframe v0.1.0 produced them.

You are reading the documentation of an outdated version, whose text may no longer be accurate. Go to the latest version.

DataFrame, Series and Index have Display(), which returns the value in every format a notebook front end may show, keyed by MIME type: text/plain (what String prints, laid out as pandas prints it) and text/html (the table pandas shows in a notebook). It is the display contract of the go-notebook kernel, so a cell whose last expression is a frame shows it as a table.

Every output on this page was produced by go-dataframe v0.1.0 from the code shown above it: figures/<name>.go in this site’s repository writes it, and the CI writes it again and fails if one byte differs.

A frame

The table the examples share, built from Go slices:

package main

func init() { registerOutput("display", display) }

// What a notebook cell whose value is a frame shows: Display returns both
// MIME types, text/plain (String) and text/html (HTML).
func display() (string, string) {
	df := rainfall()
	d := df.Display()
	return string(d["text/plain"]), string(d["text/html"])
}

A group-by 

package main

import "github.com/go-dataframe/dataframe"

func init() { registerOutput("groupby", groupby) }

// Group by city: the mean and the maximum yearly rainfall, and the rainy days
// summed over the three years.
func groupby() (string, string) {
	g := dataframe.Must(rainfall().GroupBy("city"))
	out := dataframe.Must(g.Agg(
		dataframe.Agg("rain", "mean", "max"),
		dataframe.Agg("days", "sum"),
	))
	return out.String(), out.HTML()
}

Describe 

package main

func init() { registerOutput("describe", describe) }

// df.describe(): count, mean, std, min, quartiles and max of each numeric column.
func describe() (string, string) {
	d := rainfall().Describe()
	return d.String(), d.HTML()
}
